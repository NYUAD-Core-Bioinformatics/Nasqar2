## Example: RNA-seq with DESeq2

This walkthrough takes the multi-factor example data of the DESeq2 application
from a table of raw counts to differential expression results, figures and a
reproducible R script. Every step happens in the browser; no R programming is
needed.

<LaunchButton path="/deseq2shiny/">Launch DESeq2</LaunchButton>

The steps appear in the sidebar of the application as you complete them:

1. **Input Data**: load a counts table.
2. **Design Conditions**: describe the samples and choose the design formula.
3. **Run DESeq2**: run the analysis.
4. **Explore and export**: compare conditions, plot genes, download tables and
   figures.

Click any figure on this page to enlarge it.

### The example data

The multi-factor example is a mouse experiment with nine samples and two
factors: **Genotype** (WT or KO) and **Treatment** (N4 or V4). It comes with a
sample metadata table, so you can follow every step without preparing a file.
The application also has a single-factor example without replicates.

### 1. Input Data

Under **Where is your data?** choose **Example data (multi-factor)**. To use
your own data, choose **Upload a counts file** instead.

A counts file is a plain-text table, comma or tab delimited (`.csv` or `.txt`),
with a header row:

- The first column holds the gene identifiers, one gene per row. These can be
  gene IDs or gene names.
- A file can carry both: gene IDs in the first column and gene symbols in the
  second. Choose **My matrix contains GeneIDs and GeneSymbols** and you can
  search and label genes by either.
- Every other column is one sample.
- **Counts must be raw integer read counts, not normalised values such as TPM
  or FPKM.**
- **Use only letters, digits and underscores in sample names.**

If each sample has its own counts file, combine them first with
[Gene Count Merger](/applications/data_preprocessing_and_qc/gene_count_merger).

Once the counts are loaded they are shown as a table you can page through and
search. Optionally remove genes with very low counts, then press
**Next: Conditions**.

<ImageSample1 path="/deseq2/walk-input.png"/>

**DESeq2 needs replicates to test for differential expression.** If your
samples have none, tick **No Replicates**; only exploratory analysis is then
possible.

### 2. Design Conditions

Each sample needs a value for every experimental factor. The example data
arrives with its metadata filled in. For your own data you can:

- edit the table on the page, cell by cell;
- upload a metadata file with the sample names in the first column, exactly as
  in the counts table, and one column per factor; or
- for a single-factor experiment, name the samples as condition, underscore,
  replicate number (`CT6_1`, `CT6_2`) and the table is filled in for you.

The second box adds or removes a factor and leaves outlier samples out of the
analysis. The third sets the **design formula**, the factors DESeq2 models,
joined by `+`. For the example it is `~ Genotype + Treatment`.

Press **Initialize DESeq2**.

<ImageSample1 path="/deseq2/walk-conditions.png"/>

### 3. Run DESeq2

The page shows the design formula and the first rows of the sample metadata
for a last check. The VST transformation used by the quality-control plots is
computed by default; the rlog transformation is optional because it takes
longer. Press **Run DESeq2**.

If you suspect a hidden batch effect, open **Surrogate Variable Analysis
(SVA)** first. It estimates surrogate variables with svaseq, which you can add
to the design before running DESeq2.


### 4. Check the samples

The **VST** tab (and **Rlog**, if you computed it) shows two views of how the
samples relate to each other:

- The **sample distance heatmap** clusters the samples by similarity.
  Replicates should sit next to each other.
- The **PCA plot** places the samples on the first two principal components.
  Choose the factor to colour by under **Group of interest**.

A sample that sits far from its replicates is worth a second look, and can be
excluded on the Design Conditions tab.

<ImageSample1 path="/deseq2/walk-vst.png"/>

### 5. Get results for a comparison

On the **DE Results** tab choose a factor and the two conditions to compare.
Fold changes are reported as condition 1 relative to condition 2, the
baseline. Press **Get results** for the results table and an MA plot.

Press **Save comparison** to keep a result. Saved comparisons can be
downloaded one by one or all together, opened directly in the
[enrichment applications](/applications/rna_seq/bulk_rna/enrichment), and are
what the Volcano Plot and UpSet Plot tabs work on.

Here two comparisons are saved: KO against WT, and N4 against V4.

<ImageSample1 path="/deseq2/walk-results.png"/>

### 6. Volcano plot

The **Volcano Plot** tab draws a saved comparison, with up-regulated genes in
red and down-regulated genes in blue at the significance and fold-change
thresholds you set. The most significant genes are labelled, or you can list
the genes to label. The genes that pass the thresholds are listed under the
plot. **The volcano plot needs one saved comparison.**

<ImageSample1 path="/deseq2/walk-volcano.png"/>

### 7. Compare gene lists: UpSet plot and set operations

The **UpSet Plot** tab compares the significant genes of several saved
comparisons, and answers questions such as "which genes respond to the
treatment but not to the knockout?". **It needs at least two saved
comparisons.**

Select the comparisons, choose all, up-regulated or down-regulated genes, set
the thresholds and press **Plot UpSet**. Each bar counts the genes that are
significant in exactly one combination of comparisons; the dots under the bar
show which. Click a bar to list its genes.

For a question that is not a single bar, write a set expression. Each
comparison has a letter, shown next to its name.

| Operator | Meaning | Example | Genes returned |
| --- | --- | --- | --- |
| `*` | Intersection | `A*B` | Significant in both A and B |
| `+` | Union | `A+B` | Significant in A, in B, or in both |
| `-` | Difference | `A-B` | Significant in A but not in B |
| `( )` | Grouping | `(A*B)-C` | Shared by A and B, but not significant in C |

**Expressions are read from left to right and no operator takes priority over
another, so use parentheses whenever you mix operators**: `A-(B+C)` is not the
same as `A-B+C`.

<ImageSample1 path="/deseq2/walk-upset.png"/>

### 8. Gene boxplot and heatmap

The **Gene Boxplot** tab shows the expression of the genes you choose across
your conditions.

<ImageSample1 path="/deseq2/walk-boxplot.png"/>

The **Heatmap** tab draws the most variable genes, or a set you choose. Drag
over an area of the heatmap to zoom into it as a sub-heatmap.

<ImageSample1 path="/deseq2/walk-heatmap.png"/>

### 9. Export

Every table downloads as CSV and every figure as an image, from the tab it is
on. **Export and files** in the sidebar has **Export R code**, which bundles a
script that reproduces every figure outside the application.

### On a private instance

On a private instance the Input Data tab also offers **Counts file in the
private space**, which reads a counts file from your own storage without
uploading it, and every analysis is saved under a project name. **Reopen a
saved project** brings back the data, results and plot settings as you left
them. See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data)
to set one up.
