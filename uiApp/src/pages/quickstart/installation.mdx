## Installation Options using Docker

In order to deploy NASQAR2 using the various Docker based installation option, please ensure you have already installed [Docker](https://www.docker.com/products/docker-desktop/)

### [Option 1: Pull Prebuilt Docker from Cloud](#option-1-pull-prebuilt-docker-from-cloud) (Recommended - Fastest)
Pull and run the complete NASQAR2 suite with all applications in a single Docker container. No building required - just pull and run!

### [Option 2: Build All-in-One Docker from Source](#option-2-build-all-in-one-docker-from-source)
Build the complete NASQAR2 Docker container with all applications from source code.

### [Option 3: Build Individual Docker Containers from Source](#option-3-build-individual-docker-containers-from-source)
Build and run specific NASQAR2 applications (e.g., DESeq2, DADA2, Seurat) as separate Docker containers from source. Useful for specific tools or resource optimization.

---

### Option 1: Pull Prebuilt Docker from Cloud

We provide prebuilt Docker images with all NASQAR2 applications bundled together. This is the fastest and easiest way to get started.

**Pull the image:**

```bash
docker pull nyuadcorebio/nasqarall:latest
```

**To run NASQAR2 on port 80:**

```bash
docker run -p 80:80 nyuadcorebio/nasqarall:latest
```

**To run NASQAR2 on a different port** (e.g., port 8083):

```bash
docker run -p 8083:80 nyuadcorebio/nasqarall:latest
```

Access via web browser at `http://localhost/` or `http://localhost:8083/` depending on the port used.

---

### Option 2: Build All-in-One Docker from Source

Build the complete NASQAR2 Docker container with all applications from source code.

1. **Clone NASQAR2 Repository:**

```bash
git clone https://github.com/NYUAD-Core-Bioinformatics/Nasqar2.git
cd Nasqar2
```

2. **Build Docker Image:**

```bash
docker build -t nasqar2-all .
```

3. **Run Docker Container:**

```bash
docker run -p 80:80 nasqar2-all
```

Access via web browser at `http://localhost/`

---

### Option 3: Build Individual Docker Containers from Source

Each NASQAR2 application can be run as a standalone Docker container. This is useful for running specific tools independently or reducing resource usage.

**Note**: Individual Docker containers are only available by building from source. Prebuilt images are not provided in the cloud repository.

### Available Applications

NASQAR2 includes the following applications that can be built individually:

- `animalcules` - Microbiome analysis
- `ATACseqQCShniy` - ATAC-seq quality control
- `ClusterProfShinyGSEA` - Gene Set Enrichment Analysis
- `ClusterProfShinyORA` - Over-Representation Analysis
- `dada2Shiny` - 16S/ITS amplicon sequencing analysis
- `DEBrowser` - Differential expression analysis browser
- `deseq2shiny` - DESeq2 differential expression analysis
- `GeneCountMerger` - Merge gene count matrices
- `monocle3` - Single-cell trajectory analysis
- `SeuratV5Shiny` - Single-cell RNA-seq analysis
- `tsar_nasqar` - Time series analysis

### Build Individual Docker from Source

1. **Clone NASQAR2 Repository:**

```bash
git clone https://github.com/NYUAD-Core-Bioinformatics/Nasqar2.git
cd Nasqar2
```

2. **Navigate to the specific application directory:**

**Example for DESeq2:**
```bash
cd deseq2shiny
```

**Example for DADA2:**
```bash
cd dada2Shiny
```

**Example for Seurat:**
```bash
cd SeuratV5Shiny
```

3. **Build the Docker image:**

```bash
docker build -t nasqar-deseq2 .
```

4. **Run the container:**

```bash
docker run -p 9001:3232 nasqar-deseq2
```

Access the application at `http://localhost:9001/`

## Local Installation with Anaconda

In order to deploy NASQAR2 using Conda, please ensure you have installed [Conda/MiniConda/Anaconda] on your system.

Run individual applications directly on your system without Docker. Each application has its own conda environment with specific dependencies.

### Prerequisites

- **Anaconda** or **Miniconda** installed on your system
- Download from [Anaconda](https://www.anaconda.com/products/distribution) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html)

### Setup Application-Specific Environment

Each NASQAR2 application has its own `environment.yaml` file for creating an isolated conda environment.

**Example: Setting up DESeq2 application:**

1. **Clone NASQAR2 Repository:**

```bash
git clone https://github.com/NYUAD-Core-Bioinformatics/Nasqar2.git
cd Nasqar2
```

2. **Navigate to the application directory:**

```bash
cd deseq2shiny
```

3. **Install mamba (if not already installed):**

```bash
conda install -c bioconda -c conda-forge mamba -y
```

4. **Create application-specific conda environment:**

```bash
mamba env create -f environment.yaml
```

5. **Activate the environment:**

```bash
conda activate deseq2shiny
```

6. **Navigate to the src directory:**

```bash
cd src
```

7. **Run the application:**

```bash
R -e "shiny::runApp('.', port = 9001, host = '0.0.0.0')"
```

Access the application at `http://localhost:9001/`

### Running Different Applications

**Example: Setting up DADA2 application:**

```bash
cd Nasqar2/dada2Shiny
mamba env create -f environment.yaml
conda activate dada2Shiny
cd src
R -e "shiny::runApp('.', port = 9002, host = '0.0.0.0')"
```

**Example: Setting up Seurat application:**

```bash
cd Nasqar2/SeuratV5Shiny
mamba env create -f environment.yaml
conda activate SeuratV5Shiny
cd src
R -e "shiny::runApp('.', port = 9003, host = '0.0.0.0')"
```

**Note**: Each application maintains its own isolated environment to avoid dependency conflicts.
