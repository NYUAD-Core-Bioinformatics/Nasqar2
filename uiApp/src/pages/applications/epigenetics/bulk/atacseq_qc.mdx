## ATACseqQC

ATACseqQC is a tool specifically designed for the quality control (QC) analysis of ATAC-seq (Assay for Transposase-Accessible Chromatin using sequencing) data. It offers a range of functions and metrics to assess the quality and reliability of ATAC-seq experiments. ATAC-seq is a powerful technique used to study chromatin accessibility, which provides insights into the regulatory regions of the genome.

We provide an interactive web-based application for ATAC-seq quality control analysis.

For more information about ATACseqQC, visit the [official documentation](https://bioconductor.org/packages/release/bioc/html/ATACseqQC.html).

## HPC use

In the Slurm deployment, choose **Use HPC scratch directory** to load matching
BAM and BAI files directly from the configured read-only data root. Browser
upload and bundled example data remain available.

Core, nucleosome, and footprint results are cached by BAM path, file size,
modification time, reference genome, chromosome, and motif. The cache persists
across jobs, while PT, NFR, and TSSE scoring can use allocated Slurm CPUs.

See the [HPC deployment guide](/quickstart/hpc) for storage and tunnel setup.
