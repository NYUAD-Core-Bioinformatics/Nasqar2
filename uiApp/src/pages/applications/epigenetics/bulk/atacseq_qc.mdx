## ATACseqQC

ATACseqQC is a tool specifically designed for the quality control (QC) analysis of ATAC-seq (Assay for Transposase-Accessible Chromatin using sequencing) data. It offers a range of functions and metrics to assess the quality and reliability of ATAC-seq experiments. ATAC-seq is a powerful technique used to study chromatin accessibility, which provides insights into the regulatory regions of the genome.

We provide an interactive web-based application for ATAC-seq quality control analysis.

For more information about ATACseqQC, visit the [official documentation](https://bioconductor.org/packages/release/bioc/html/ATACseqQC.html).

## Private instance use

When NASQAR2 runs as a private instance with a data root configured, choose
**Use a directory in the private space** to load matching BAM and BAI
files directly from that read-only directory instead of uploading them.
Browser upload and bundled example data remain available.

Core, nucleosome, and footprint results are cached by BAM path, file size,
modification time, reference genome, chromosome, and motif. The cache persists
across sessions and jobs; on Slurm, PT, NFR, and TSSE scoring can use the
allocated CPUs.

See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) for Docker and the [HPC deployment guide](/quickstart/hpc) for Slurm.

## Private-space projects

In a private instance every run belongs to a project, `projects/ATACseqQC/<name>`,
holding BAM directory, genome and the per-project result caches plus a `state.rds` of the settings and the stage reached.
**Restore an existing project** on the input tab reopens it without
recomputing; cached results are reused and the restore is refused if the
source data changed. Public instances have no private space and no projects.
