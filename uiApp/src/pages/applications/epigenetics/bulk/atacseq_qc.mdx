## ATACseqQC

The ATACseqQC application checks the quality of ATAC-seq experiments with the
Bioconductor package [ATACseqQC](https://bioconductor.org/packages/release/bioc/html/ATACseqQC.html).
It reports library complexity, the fragment size distribution, signal around
transcription start sites and transcription factor footprints.

<LaunchButton path="/ATACseqQCShniy/">Launch ATACseqQC</LaunchButton>

## What you need

- Aligned reads as BAM files, **each with its BAI index**.
- The reference genome the reads were aligned to, chosen in the application.

An example data set is included to try the steps first.

## On a private instance

On a private instance you can also choose **BAM folder in the private space**
to read BAM and BAI files from your own storage instead of uploading them.
Results of such a run are saved under a project name, so **Reopen a saved
project** shows them again without recomputing. The public site has no private
space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
