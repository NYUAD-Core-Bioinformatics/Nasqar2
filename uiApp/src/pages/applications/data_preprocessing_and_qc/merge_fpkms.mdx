## Merge FPKMs

This is a simple preprocessing tool to merge individual gene FPKM files (e.g., FPKM files from cufflinks).

We provide an interactive web-based application for merging FPKM files.

**Note**: The first column must contain the genes. If the gene columns do not match in all files, this tool will not work.
