## Merge FPKMs

Merge FPKMs combines the FPKM files of individual samples, such as the gene
FPKM tables written by Cufflinks, into one table with a column per sample.

<LaunchButton path="/mergeFPKMs/">Launch Merge FPKMs</LaunchButton>

## What you need

- One FPKM file per sample.
- **The first column of every file must hold the genes, and the genes must be
  the same in all files.** Files with different gene lists cannot be merged.

## Where it fits

Merge FPKMs is a preprocessing step. **FPKM values are normalised, so the
merged table is not a valid input for DESeq2**, which needs raw counts. Use
[Gene Count Merger](/applications/data_preprocessing_and_qc/gene_count_merger)
for raw counts.

## On a private instance

On a private instance you can also choose **Files in the private space** and
pick the FPKM files from your own storage instead of uploading them, and
**Reopen a saved project** to return to an earlier merge. The merged table is saved automatically under the project name you give. The public site has
no private space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
