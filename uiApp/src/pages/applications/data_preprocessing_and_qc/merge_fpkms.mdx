## Merge FPKMs

This is a simple preprocessing tool to merge individual gene FPKM files (e.g., FPKM files from cufflinks).

We provide an interactive web-based application for merging FPKM files.

**Note**: The first column must contain the genes. If the gene columns do not match in all files, this tool will not work.

<a href={`${process.env.NEXT_PUBLIC_NASQAR_BASE_PATH || ''}/mergeFPKMs/`} target="_blank" style={{display: 'inline-block', padding: '8px 16px', marginTop: '1rem', backgroundColor: '#3b82f6', color: 'white', textDecoration: 'none', borderRadius: '6px', fontSize: '14px'}}>
  Launch Merge FPKMs
</a>

In a private instance, **Use files in the private space** lets you pick the FPKM files to merge in a Browse dialog (several at once, or paste their paths); they are read in place.

## Private-space projects

In a private instance every run belongs to a project, `projects/mergeFPKMs/<name>`,
holding the merged table plus a `state.rds` of the settings and the stage reached.
**Restore an existing project** on the input tab reopens it without
recomputing; cached results are reused and the restore is refused if the
source data changed. Public instances have no private space and no projects.
