## Gene Count Merger

This is a simple preprocessing tool to merge individual gene count files (e.g., output count files from htseq).

We provide an interactive web-based application for merging gene count files.

**Note**: The first column must contain the genes. If the gene columns do not match in all files, this tool will not work.
