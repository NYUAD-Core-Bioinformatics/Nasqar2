## Gene Count Merger

Gene Count Merger combines the count files of individual samples, or several
count matrices, into one matrix that is ready for analysis. It reads raw counts
from tools such as HTSeq and featureCounts, and gene-level estimated counts
from Kallisto.

<LaunchButton path="/GeneCountMerger/">Launch Gene Count Merger</LaunchButton>

## What you need

- One count file per sample, or two or more count matrices.
- **The first column of every file must hold the same gene identifiers.** When
  matrices are merged, matching identifiers are joined even if the rows are in
  a different order.

## Where it fits

Gene Count Merger is the first step of a bulk RNA-seq analysis. The merged
matrix can be downloaded, or opened directly in [DESeq2](/applications/rna_seq/bulk_rna/deseq2)
or [START](/applications/rna_seq/bulk_rna/startapp).

**Gene Count Merger does not merge single-cell data.** Load single-cell
matrices directly into [Seurat v5](/applications/rna_seq/single_cell/seuartV5).

## On a private instance

On a private instance you can also choose **Files in the private space** and
pick the count files from your own storage instead of uploading them. The
merged matrix is saved automatically in the project you create or open at the
start, and DESeq2 opened on the same project fills it in as its input. Uploaded
count files are kept in the project as well. When you reopen the project, the count files and the
merge settings are filled in, so you can change a setting, such as adding gene names, and merge
again without uploading them. **Kallisto files are always uploaded and are not kept.** The public site has no private space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
