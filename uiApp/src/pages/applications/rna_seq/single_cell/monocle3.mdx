## Monocle3

Monocle 3 is a computational tool for analyzing single-cell RNA sequencing (scRNA-seq) data, specializing in inferring dynamic biological processes such as cell differentiation.

We provide an interactive web-based application for Monocle3 analysis.

For more information about Monocle3, visit the [official documentation](https://cole-trapnell-lab.github.io/monocle3/).

## HPC use

Choose **Use HPC scratch file** to load a Seurat `.rds` or `.RData` object
inside the configured read-only data root. Monocle 3 validates that the path
remains inside that root and writes trajectory outputs to a named persistent
project directory. Worker availability is derived from
`SLURM_CPUS_PER_TASK`.

See the [HPC deployment guide](/quickstart/hpc) for submission, storage, and
SSH tunnel instructions.
