## Monocle 3

The Monocle 3 application infers trajectories from single-cell RNA-seq data
with [Monocle 3](https://cole-trapnell-lab.github.io/monocle3/): it orders
cells along a process such as differentiation and assigns each a pseudotime.

<LaunchButton path="/monocle3/">Launch Monocle 3</LaunchButton>

## What you need

- **A processed Seurat object** (`.rds` or `.RData`), already clustered.
  Monocle 3 does not start from raw counts.

## Where it fits

Monocle 3 is the second step of the single-cell workflow, after
[Seurat v5](/applications/rna_seq/single_cell/seuartV5). An object finished in
Seurat v5 can be opened in Monocle 3 directly, without downloading it.

## On a private instance

On a private instance you can also choose **Seurat object in the private
space** to read the object from your own storage instead of uploading it, and
**Reopen a saved project** to return to an earlier run. **Only projects made
from an object in the private space can be reopened.** The public site has no
private space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
