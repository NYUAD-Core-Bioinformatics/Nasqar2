## Monocle3

Monocle 3 is a computational tool for analyzing single-cell RNA sequencing (scRNA-seq) data, specializing in inferring dynamic biological processes such as cell differentiation.

We provide an interactive web-based application for Monocle3 analysis.

For more information about Monocle3, visit the [official documentation](https://cole-trapnell-lab.github.io/monocle3/).

## Private instance use

In a private instance, choose **Use a file in the private space** to load
a Seurat `.rds` or `.RData` object from the configured read-only data root.
Monocle 3 validates that the path remains inside that root and writes
trajectory outputs to a named persistent project directory. On Slurm, worker
availability is derived from `SLURM_CPUS_PER_TASK`.

See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) for Docker and the [HPC deployment guide](/quickstart/hpc) for Slurm.

## Private-space projects

In a private instance every run belongs to a project, `projects/Monocle3/<name>`,
holding input object, assay, identity, progenitor gene and the complete run results plus a `state.rds` of the settings and the stage reached.
**Restore an existing project** on the input tab reopens it without
recomputing; cached results are reused and the restore is refused if the
source data changed. Public instances have no private space and no projects.
