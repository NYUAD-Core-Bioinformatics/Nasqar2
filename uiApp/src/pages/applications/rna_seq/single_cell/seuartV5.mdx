## Seurat V5

Seurat is an R package designed for QC, analysis, and exploration of single-cell RNA-seq data. Seurat aims to enable users to identify and interpret sources of heterogeneity from single-cell transcriptomic measurements, and to integrate diverse types of single-cell data.

We provide an interactive web-based application for Seurat V5 analysis.

For more information about Seurat, visit the [official documentation](https://satijalab.org/seurat/).

## HPC use

The HPC input mode loads supported count matrices or Seurat objects directly
from the configured read-only data root. Select a persistent project name for
outputs that must remain available after the Slurm job ends. Worker
availability is derived from `SLURM_CPUS_PER_TASK`.

Use the direct Seurat v5 to Monocle 3 handoff for compatible processed objects,
or save the object in persistent project storage. See the
[HPC deployment guide](/quickstart/hpc).
