## Seurat v5

The Seurat v5 application takes single-cell RNA-seq counts through quality
control, filtering, normalisation, PCA, clustering and marker detection with
[Seurat](https://satijalab.org/seurat/), without any R programming.

<LaunchButton path="/SeuratV5Shiny/">Launch Seurat v5</LaunchButton>

## What you need

One of:

- a count matrix as a `.csv` file, or
- the files of a 10x Genomics run.

An example data set (PBMC) is included to try the steps first.

## Where it fits

Seurat v5 is the first step of the single-cell workflow. The finished Seurat
object can be downloaded, or opened directly in
[Monocle 3](/applications/rna_seq/single_cell/monocle3) for trajectory analysis.

## On a private instance

On a private instance you can also choose **Data in the private space** to
read a 10x folder or a count matrix from your own storage instead of uploading
it. Every analysis is saved under a project name, and **Reopen a saved
project** returns to it. **Only projects made from data in the private space
can be reopened.** The public site has no private space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
