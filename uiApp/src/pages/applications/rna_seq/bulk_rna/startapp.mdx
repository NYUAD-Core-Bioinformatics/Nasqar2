## START

START (Shiny Transcriptome Analysis Resource Tool) is a web-based resource for
analysing and visualising RNA-seq data. It is an alternative to the DESeq2
application for exploring a count matrix.

<LaunchButton path="/tsar_nasqar/">Launch START</LaunchButton>

## Where it fits

A matrix merged in [Gene Count Merger](/applications/data_preprocessing_and_qc/gene_count_merger)
can be opened directly in START.
