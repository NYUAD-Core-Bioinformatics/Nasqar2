## DESeq2

This Shiny app is a wrapper around DESeq2, an R package for "Differential gene expression analysis based on the negative binomial distribution".

We provide an interactive web-based application for DESeq2 analysis.

For more information about DESeq2, visit the [official documentation](https://bioconductor.org/packages/release/bioc/html/DESeq2.html).

## Save and restore in a private instance

DESeq2 follows the same project convention as every other NASQAR2 application:
the Input Data tab carries **Persistent project name**, **Reload a previous
analysis** and the gallery of saved plots and files. Loading counts records the
project; once DESeq2 has run, the full application state
(`projects/DESeq2Shiny/<name>/state.RData`) is saved automatically and saved
again whenever you change settings, so restoring reloads all data, results and
plot settings as you left them. **Export R code and all plots (zip)** on the
same tab bundles the reproducible R script with every figure (and is kept in
the project like any other download). The former Save/Load State view has been
removed.

## Private-space projects

In a private instance every run belongs to a project, `projects/DESeq2Shiny/<name>`,
holding the full application state (`state.RData`), saved from the Save/Load State view plus a `state.rds` of the settings and the stage reached.
**Restore an existing project** on the input tab reopens it without
recomputing; cached results are reused and the restore is refused if the
source data changed. Public instances have no private space and no projects.
