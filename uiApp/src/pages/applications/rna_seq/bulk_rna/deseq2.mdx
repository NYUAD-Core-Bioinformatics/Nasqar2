## DESeq2

This Shiny app is a wrapper around DESeq2, an R package for "Differential gene expression analysis based on the negative binomial distribution".

We provide an interactive web-based application for DESeq2 analysis.

For more information about DESeq2, visit the [official documentation](https://bioconductor.org/packages/release/bioc/html/DESeq2.html).

## Save and restore in a private instance

On the Input Data tab, **Where is your data?** decides what the box shows.
For a new analysis (an uploaded file, a file in the private space or the
example data) it asks for a **Project name**. Loading counts records the
project; once DESeq2 has run, the full application state
(`projects/DESeq2Shiny/<name>/state.RData`) is saved automatically and saved
again whenever you change settings. Choosing **Reopen a saved project** shows
the saved projects of the instance instead; **Open project** reloads all data,
results and plot settings as you left them, without recomputing.

**Export and files** in the sidebar holds both ways out of the app: **Export R
code** bundles the reproducible R script with every figure, and the list next to
it shows the plots and tables downloaded in the current project (the export is
kept there like any other download).
There is no separate state-file download or upload: projects are the only way
to save and reopen an analysis, and public instances have no private space and
no projects.

## Private-space projects

In a private instance every run belongs to a project, `projects/DESeq2Shiny/<name>`,
holding the full application state (`state.RData`) plus a `state.rds` of the
settings and the stage reached. A project that only has loaded counts cannot be
reopened yet: run DESeq2 first.
