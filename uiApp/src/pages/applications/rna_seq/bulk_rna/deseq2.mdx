## DESeq2

The DESeq2 application runs differential expression analysis on a table of raw
RNA-seq counts with [DESeq2](https://bioconductor.org/packages/release/bioc/html/DESeq2.html),
without any R programming. Single-factor and multi-factor designs are
supported, as is exploratory analysis without replicates.

<LaunchButton path="/deseq2shiny/">Launch DESeq2</LaunchButton>

For a step-by-step walkthrough with figures, see
[Example: RNA-seq with DESeq2](/quickstart/deseq2).

## What you need

- A table of raw counts (`.csv` or `.txt`) with one gene per row and one
  sample per column. The first column holds gene IDs or gene names; a second
  column of gene symbols is optional.
- **Counts must be raw integer read counts, not normalised values such as TPM
  or FPKM.**
- **DESeq2 needs replicates to test for differential expression.** Without
  replicates only exploratory analysis is possible.
- For a multi-factor experiment, a sample metadata table with one row per
  sample and one column per factor. It can also be typed in on the page.

## What you get

- PCA plot and sample distance heatmap of the VST or rlog values.
- Results table and MA plot for every comparison you choose.
- Volcano plot of a saved comparison.
- UpSet plot and set operations to compare the gene lists of several saved
  comparisons.
- Gene boxplots and an interactive heatmap.
- **Export R code**, which reproduces every figure outside the application.

## Where it fits

DESeq2 is the first step of the bulk RNA-seq workflow. Counts usually come
from [Gene Count Merger](/applications/data_preprocessing_and_qc/gene_count_merger),
and a comparison can be opened directly in the
[enrichment applications](/applications/rna_seq/bulk_rna/enrichment).

## On a private instance

On a private instance you can also choose **Counts file in the private space**
to read a counts file from your own storage instead of uploading it. Every
analysis is saved in a project, and opening the project again brings back the
data, results and plot settings as you left them. Opened on a project where
Gene Count Merger saved a merged table, that table is filled in as the input. **A project can be
reopened only after DESeq2 has run in it.** The **Export and files** page lists
the figures and tables saved in the project. The public site has no private
space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
