## DESeq2

This Shiny app is a wrapper around DESeq2, an R package for "Differential gene expression analysis based on the negative binomial distribution".

We provide an interactive web-based application for DESeq2 analysis.

For more information about DESeq2, visit the [official documentation](https://bioconductor.org/packages/release/bioc/html/DESeq2.html).

## Save and restore on HPC

The **Save/Load State & Export** view retains normal browser download and
upload. In the Slurm deployment it also displays **HPC Scratch** controls for
saving and restoring `.RData` analysis states in a private persistent
directory. Saved states remain available after the current job ends.

The HPC state area is enabled only when the deployment supplies a writable
`NASQAR_DESEQ2_STATE_DIR`. See the
[HPC deployment guide](/quickstart/hpc).
