## DEBrowser

DEBrowser is a web-based platform for iterative, interactive analysis of count
data without any programming. It is an alternative to the DESeq2 application.

For more information, see the [DEBrowser documentation](https://www.bioconductor.org/packages/release/bioc/vignettes/debrowser/inst/doc/DEBrowser.html).
