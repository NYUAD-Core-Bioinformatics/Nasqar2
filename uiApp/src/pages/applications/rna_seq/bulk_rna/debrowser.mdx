## DEBrowser

DEBrowser is a flexible, intuitive, web-based analysis platform that enables an iterative and interactive analysis of count data without any requirement of programming knowledge.

We provide an interactive web-based application for DEBrowser analysis.

For more information about DEBrowser, visit the [official documentation](https://www.bioconductor.org/packages/release/bioc/vignettes/debrowser/inst/doc/DEBrowser.html).
