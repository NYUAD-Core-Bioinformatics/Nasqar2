## Animalcules

Animalcules is an interactive R Shiny application for utilizing up-to-date data analytics, visualization methods, and machine learning models to provide users an easy-to-use interactive microbiome analysis framework.

We provide an interactive web-based application for Animalcules analysis.

For more information about Animalcules, visit the [official documentation](https://compbiomed.github.io/animalcules-docs/).
