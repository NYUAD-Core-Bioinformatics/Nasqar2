## DADA2

The DADA2 application processes amplicon sequencing reads with
[DADA2](https://benjjneb.github.io/dada2/): it filters and trims the reads,
corrects sequencing errors, infers amplicon sequence variants, removes
chimeras and assigns taxonomy, then summarises diversity and abundance.

<LaunchButton path="/DADA2Shiny/">Launch DADA2</LaunchButton>

## What you need

- Demultiplexed FASTQ files, single-end or paired-end, one file (or pair) per
  sample.

An example data set (mothur MiSeq SOP) is included to try the steps first.

## Where it fits

DADA2 is the first step of the metagenomics workflow.
[Animalcules](/applications/meta_genomics/animalcules) continues with
interactive microbiome analysis.

## On a private instance

On a private instance you can also choose **FASTQ folder in the private
space** to read the reads from your own storage instead of uploading them.
Every run is saved in a project, and opening the project again returns to it
without running DADA2 again. **Only projects made from a FASTQ
folder in the private space can be reopened.** The public site has no private
space and no saved projects.
See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) to set one up.
