## DADA2

DADA2 is a tool for modeling and correcting Illumina-sequenced amplicon errors. It provides high-resolution inference of amplicon sequence variants from amplicon data.

We provide an interactive web-based application for DADA2 analysis.

For more information about DADA2, visit the [official documentation](https://benjjneb.github.io/dada2/).

## HPC use

Choose the HPC scratch input mode to load paired FASTQ files directly from the
configured read-only data root. Give the run a project name so filtered reads,
sequence tables, taxonomy results, and downloadable outputs persist under the
DADA2 project directory.

Filtering and trimming use node-local temporary storage. Parameter-aware
caches include the input paths and file metadata, DADA2 parameters, and package
version. Parallel steps derive available workers from
`SLURM_CPUS_PER_TASK`.

See the [HPC deployment guide](/quickstart/hpc) for storage and submission
details.
