
 


# Overview

Welcome to our platform! Here, we offer a diverse range of web-based Bioinformatics analysis and visualization applications. Whether you prefer running apps online or downloading them to run on your local machine, we provide both options.

To install NASQAR2 on your local system, please follow the instructions on our [Installation Guide](/quickstart/installation) or visit our [GitHub page](https://github.com/NYUAD-Core-Bioinformatics/Nasqar2).

The field of high-throughput sequencing is continually evolving, resulting in a rapid increase in both the quantity and diversity of sequence-based data. This growth necessitates the development of new software libraries and tools for effective data analysis and visualization. However, utilizing these tools often requires computational skills beyond the expertise of the average researcher.

To address this challenge, we introduce NASQAR2, a dynamic web-based platform designed to lower the computational barrier. NASQAR2 features an intuitive interface that enables users to easily and efficiently explore their data interactively. Our platform integrates popular tools tailored for various applications, including Transcriptome Data Preprocessing, RNAseq Analysis (including Single-cell RNAseq), Metagenomics, and Gene Enrichment. Explore your data seamlessly and unlock insights with NASQAR.

## NASQAR2 Updates

**Runtime and deployment**

* **R 4.3.3** across the analytical module images
* Deploy the complete platform as one Docker image or run individual module images
* Run NASQAR2 as an unprivileged Singularity container in a Slurm compute job
* Access approved HPC scratch datasets directly and preserve projects, states, results, and caches across jobs
* **HPC-aware applications:** ATACseqQC, DESeq2Shiny, DADA2, Seurat v5, and Monocle 3

See the [HPC Deployment Guide](/quickstart/hpc) for image preparation, job submission, storage configuration, and SSH tunnel instructions.

**New applications**

* **DADA2** - Amplicon quality filtering, ASV inference, chimera removal, and taxonomy assignment
* **ATACseqQC** - ATAC-seq quality metrics, nucleosome positioning, and transcription-factor footprint analysis
* **Animalcules** - Interactive microbiome analysis and visualization

**Connected workflows**

* **Gene Count Merger → DESeq2Shiny or START** for bulk RNA-seq analysis
* **DESeq2Shiny → ORA or GSEA** with the selected contrast transferred automatically
* **DADA2 → Animalcules** with ASV and taxonomy results transferred automatically
* **Seurat v5 → Monocle 3** with a compatible processed single-cell object

**Major module enhancements**

* **Gene Count Merger** - Merges HTSeq/featureCounts files, Kallisto estimated counts, or existing matrices; supports gene-symbol annotation and custom gene-ID mappings
* **DESeq2Shiny** - Design metadata, multiple contrasts, PCA, volcano and MA plots, interactive heatmaps, Venn comparisons, portable save/restore states, publication-ready downloads, and reproducible R-code export
* **ClusterProfShinyGSEA and ClusterProfShinyORA** - GO/KEGG tables and plots, identifier conversion, direct DESeq2 handoff, online KEGG viewing, and downloadable Pathview PNG/PDF output
* **DADA2** - Persistent projects, parameter-aware caching, taxonomy downloads, publication-ready figures, and direct Animalcules handoff
* **ATACseqQC** - Cached core QC plus on-demand nucleosome and footprint analyses with publication-ready figure downloads
* **Seurat v5 and Monocle 3** - Persistent HPC projects, allocated-worker support, and direct trajectory-analysis handoff



## Data Privacy

Although data uploaded for analysis on the online instance of 
NASQAR2 (at http://nasqar2.abudhabi.nyu.edu/) is by default discarded after a users session ends, this does not guarantee total data privacy. In cases where data privacy is a concern (e.g. patient or pilot data), it is recommended that NASQAR2 is deployed on a local intranet for private users, or on a personal computer. A Docker image of NASQAR2 is publicly available through DockerHub and can be used to deploy the application seamlessly on any system with Docker installed, whether a local computer, a public internet server, or a private server (e.g. research institutions intranet).
