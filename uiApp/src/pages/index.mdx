
 


# Overview

NASQAR2 is a collection of web-based applications for analysing and visualising high-throughput sequencing data. Each application wraps a widely used R package in a point-and-click interface, so you can explore your data interactively without programming.

The applications cover count preprocessing, bulk and single-cell RNA-seq, enrichment analysis, metagenomics, ATAC-seq quality control and variant annotation. Several of them are connected, so the result of one step opens directly in the next.

You can use NASQAR2 on this site, or install it on your own computer or cluster: see the [Installation Guide](/quickstart/installation) or our [GitHub page](https://github.com/NYUAD-Core-Bioinformatics/Nasqar2).

## NASQAR2 Updates

**Runtime and deployment**

* **R 4.3.3** across the analytical module images
* Deploy the complete platform as one Docker image or run individual module images
* Run NASQAR2 as a **private instance** on your own machine or cluster: your data stays where it is, files are read without uploading, and every analysis is saved so it can be reopened later
* The public site keeps nothing on the server beyond your session and offers browser upload only

See [Run as a private instance](/quickstart/installation#run-as-a-private-instance-with-your-own-data) for Docker and the [HPC Deployment Guide](/quickstart/hpc) for image preparation, job submission, storage configuration, and SSH tunnel instructions.

**New applications**

* **DADA2** - Amplicon quality filtering, ASV inference, chimera removal, and taxonomy assignment
* **ATACseqQC** - ATAC-seq quality metrics, nucleosome positioning, and transcription-factor footprint analysis
* **Animalcules** - Interactive microbiome analysis and visualization
* **Variant Annotation** - VCF filtering, transcript-level consequence prediction with VariantAnnotation (hg38/hg19), dbSNP rsIDs, and summary figures

**Connected workflows**

* **Gene Count Merger → DESeq2 or START** for bulk RNA-seq analysis
* **DESeq2 → ORA or GSEA** with the selected contrast transferred automatically
* **DADA2 → Animalcules** with ASV and taxonomy results transferred automatically
* **Seurat v5 → Monocle 3** with a compatible processed single-cell object
* **Variant Annotation → ORA** with the genes carrying variants transferred automatically

**Major module enhancements**

* **Gene Count Merger** - Merges HTSeq/featureCounts files, Kallisto estimated counts, or existing matrices; supports gene-symbol annotation and custom gene-ID mappings
* **DESeq2** - Sample metadata, multiple contrasts, PCA, volcano and MA plots, interactive heatmaps, UpSet comparisons with set operations, publication-ready downloads, and reproducible R-code export
* **GSEA and ORA** - GO/KEGG tables and plots, identifier conversion, direct DESeq2 handoff, online KEGG viewing, and downloadable Pathview PNG/PDF output
* **DADA2** - Taxonomy downloads, publication-ready figures, and direct Animalcules handoff
* **ATACseqQC** - Core QC plus on-demand nucleosome and footprint analyses with publication-ready figure downloads
* **Seurat v5 and Monocle 3** - Direct handoff of a finished Seurat object to trajectory analysis



## Data Privacy

Although data uploaded for analysis on the online instance of 
NASQAR2 (at http://nasqar2.abudhabi.nyu.edu/) is by default discarded after a user's session ends, this does not guarantee total data privacy. In cases where data privacy is a concern (e.g. patient or pilot data), it is recommended that NASQAR2 is deployed on a local intranet for private users, or on a personal computer. A Docker image of NASQAR2 is publicly available through DockerHub and can be used to deploy the application seamlessly on any system with Docker installed, whether a local computer, a public internet server, or a private server (e.g. a research institution's intranet).
